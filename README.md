# Visakh Vijayan - Playwright Test Automation Framework

This framework automates end-to-end tests for Visakh Vijayan's personal website. It leverages Playwright with TypeScript, Page Object Model, and Allure reporting for comprehensive test coverage.

## Framework Overview

| Component | Description |
|-----------|-------------|
| **Tool** | Playwright |
| **Language** | TypeScript |
| **Pattern** | Page Object Model |
| **Reporting** | Allure |
| **CI/CD** | GitHub Actions |

## Project Structure

```
├── src/
│   ├── pages/        # Page Object Model classes
│   ├── components/   # Reusable UI components
│   ├── utils/        # Logger, env helpers
│   └── fixtures/     # Custom test fixtures
├── tests/            # Test specifications
├── config/           # Playwright configuration
├── test-data/        # Test data files
└── .github/workflows/playwright.yml
```

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
npm install
npx playwright install
```

### Configuration

Copy `.env.example` to `.env` and update values:

```bash
BASE_URL=https://www.visakhvijayan.com/
```

### Run Tests

```bash
# Headless
npm test

# Headed mode
npm run test:headed

# Debug mode
npm run test:debug
```

### Allure Reports

```bash
npm run report
```

## GitHub Actions

The `.github/workflows/playwright.yml` file configures:
- Node.js installation
- Playwright browser setup
- Test execution on push/PR to `main`
- Allure and test-results artifact uploads

Add `BASE_URL` as a repository secret in GitHub (Settings → Secrets and variables → Actions).
